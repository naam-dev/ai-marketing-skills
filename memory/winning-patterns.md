# Winning Patterns

**Owner:** Human QA (Phase 1) → Marketing Agent (Phase 3+, from experiment readouts).
**Read by:** Content Agent before every draft.

What demonstrably worked — hooks, formats, angles, structures. A pattern earns a spot here with **evidence**, not vibes. In Phase 1 "evidence" = organic performance you observed; from Phase 3 it must cite an `experiment-log.jsonl` id.

Entry format:

```markdown
## [Pattern name]
- **What:** [the repeatable move — hook style, structure, angle, format]
- **Where it works:** [channels / content types / ICP segments]
- **Evidence:** [metric + comparison, e.g. "3 posts avg 4.2% ER vs 1.1% account baseline" or exp-id]
- **Example:** [content-log id or link]
- **Date added:** YYYY-MM-DD
```
