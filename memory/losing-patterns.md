# Losing Patterns

**Owner:** Human QA (Phase 1) → Marketing Agent (Phase 3+, from kill logs).
**Read by:** Content Agent before every draft — these are pre-draft point docks, same idea as `content-ops/references/patterns.md` rejection patterns.

What died and why. Equally valuable as winners (blueprint §7): a documented loss prevents the same money being spent twice.

Entry format:

```markdown
## [Pattern name]
- **What:** [the move that failed]
- **Where it failed:** [channels / content types / segments]
- **Evidence:** [metric, e.g. "2 ad sets killed at $150 spend, CTR 0.4% vs 1.8% cohort" or exp-id]
- **Hypothesis why:** [best guess — helps avoid over-generalizing the kill]
- **Rule going forward:** [what the Content Agent should do differently]
- **Date added:** YYYY-MM-DD
```
