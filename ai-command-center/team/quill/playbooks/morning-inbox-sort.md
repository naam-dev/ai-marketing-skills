# Morning inbox sort

1. Look at everything since your last shift (the last run time is at the bottom of `notes.md`; default: last 24 hours).
2. Sort each thread: needs the owner, needs a reply, FYI, noise.
3. For "needs a reply": write a draft in the brand voice (Gmail draft if enabled, otherwise `work/drafts/YYYY-MM-DD-<who>.md`).
4. Route proposal requests to Atlas and content requests to Nova with `acc send`.
5. Raise one review card, "Inbox YYYY-MM-DD", listing: the "needs the owner" items, each draft (who, subject, one line), and anything routed.
6. Write the run time at the bottom of `notes.md`.
